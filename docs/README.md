# Task 2: City Weather & Library Info (Objective-C)

## 📱 Project Name

**CityWeatherLibrary** — приложение для отображения погоды и информации о библиотеках городов на языке Objective-C.

## 📝 Description

Приложение позволяет пользователю выбирать город и получать информацию о:
- 🌡️ **Температуре** в городе (с цветовой индикацией)
- 🏛️ **Стране**, в которой находится город
- 📚 **Изображении библиотеки** города
- 📍 **Адресе библиотеки**

### 🎯 Цель работы (Задание 2.1 + Вариант 7)

1. **Упражнение 2.1:** Реализовать программу показа погоды для 6 городов с цветовой индикацией температуры и локализацией на 3 языка
2. **Вариант 7:** Дополнить приложение функционалом вывода изображения библиотеки города и её адреса

### ✨ Features

- ✅ Отображение температуры для 4 городов в 2 странах (Беларусь, Литва)
- ✅ Цветовая индикация температуры (от синего до красного)
- ✅ Изображение библиотеки для каждого города
- ✅ Адрес библиотеки с локализацией
- ✅ Локализация на 3 языка: русский, английский, белорусский
- ✅ Выбор страны через UISegmentedControl (динамическое обновление городов)
- ✅ Использование массивов и словарей для хранения данных
- ✅ Стиль кода соответствует руководству Objective-C
