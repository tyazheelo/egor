# Task 5: Two-Scene Volume Calculator (UIKit + AutoLayout)

## 📱 Project Name

**VolumeCalculator** — простое мобильное приложение с двумя сценами для расчёта объёма цилиндра и конуса с поддержкой локализации и адаптацией под разные ориентации экрана.

## 📝 Description

Приложение состоит из двух сцен (экранов) и позволяет пользователю:
- **Сцена 1 (MainScreen)** — ввод параметров (радиус, высота, выбор фигуры)
- **Сцена 2 (ResultScreen)** — отображение результата расчёта объёма

### 🎯 Цель работы (Задание 5 + Вариант 7)

1. Реализовать простое приложение на языке Swift с использованием UIKit
2. Создать приложение из **2-х сцен** (экранов)
3. Адаптировать приложение для **книжной и альбомной ориентации**
4. Адаптировать под **разные размеры экранов** (iPhone SE, iPhone 14, iPad)
5. Реализовать **локализацию на 3 языка** (русский, английский, белорусский)
6. Использовать **AutoLayout и StackView** для адаптации интерфейса
7. **Вариант 7:** Расчёт объёма цилиндра и конуса

### ✨ Features

#### Навигация (2 сцены)
- ✅ **Сцена 1 (Input Screen)** — ввод данных: радиус, высота, выбор фигуры
- ✅ **Сцена 2 (Result Screen)** — отображение рассчитанного объёма
- ✅ Навигация между сценами через `UINavigationController`
- ✅ Передача данных между сценами через `prepare(for:sender:)`

#### Ввод данных
- ✅ TextField для радиуса (м)
- ✅ TextField для высоты (м)
- ✅ SegmentedControl для выбора фигуры (Цилиндр/Конус)
- ✅ Кнопка "Рассчитать" для перехода ко 2-й сцене
- ✅ Кнопка "Очистить" для сброса полей

#### Отображение результата

- ✅ Кнопка "Назад" для возврата к вводу
- ✅ Кнопка "Поделиться" для экспорта результата

#### Адаптация (AutoLayout + StackView)

## 📊 Формулы расчёта (Вариант 7)

### Цилиндр
```
V = π × R² × H
```
где:
- V — объём (м³)
- π ≈ 3.14159265359
- R — радиус основания (м)
- H — высота (м)

### Конус
```
V = (1/3) × π × R² × H
```
