# Task 1: Background Switcher

## 📝 Description

Приложение позволяет пользователю переключать фон контроллера между двумя изображениями:
- **В положении "Вкл"** — отображается изображение `bg1.jpg`
- **В положении "Выкл"** — отображается изображение `bg2.jpg`

При переключении также обновляется текст на Label, указывающий текущий активный фон.

### 🎯 Цель работы

Научиться работать с графическими ресурсами приложения (Assets.xcassets), создавать IBOutlet и IBAction связи в Interface Builder, программировать логику переключения состояния интерфейса на языке Swift 5.

### ✨ Features

- Переключение фона с помощью UISwitch
- Отображение текущего состояния через UILabel
- Использование паттерна `UIImage(patternImage:)` для заливки фона
- Адаптация под Swift 5 (исходный код был написан для Swift 3)
- Комментарии в стиле MARK, TODO, FIXME
