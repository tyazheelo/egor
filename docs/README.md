# Task 4: RGBullsEye (SwiftUI)

## 📱 Project Name

**RGBullsEye** — интерактивная игра на SwiftUI, в которой нужно подобрать цвет, максимально близкий к целевому, с помощью трёх RGB-ползунков.

## 📝 Description

Игра проверяет ваше цветовосприятие: на экране отображается **целевой цвет**, а с помощью ползунков красного, зелёного и синего каналов вы должны создать **цвет-догадку**. Чем ближе ваш цвет к целевому, тем выше балл!

### 🎯 Цель работы (Задание 4)

Разобрать и реализовать пример из статьи **"SwiftUI: Getting Started"** (Ray Wenderlich / Kodeco), изучить основные концепции SwiftUI:
- Декларативный синтаксис
- `@State` и `@Binding` для управления состоянием
- Композиция представлений (VStack, HStack)
- Переиспользуемые компоненты
- Алерты и навигация

### ✨ Features

- ✅ Случайная генерация целевого цвета каждый раунд
- ✅ Три ползунка для выбора RGB-компонентов (Red, Green, Blue)
- ✅ Визуальное отображение цветовых блоков (target и guess)
- ✅ Отображение числовых значений RGB (0-255)
- ✅ Расчёт точности совпадения цветов (от 0 до 100 баллов)
- ✅ Подсчёт общего счёта за несколько раундов
- ✅ Отслеживание количества раундов
- ✅ Алерт с результатом после нажатия "Hit Me!"
- ✅ Кнопка "New Round" для генерации нового целевого цвета
- ✅ Адаптация под тёмную тему
- ✅ Поддержка портретной и ландшафтной ориентации

## 🎮 Как играть

1. Посмотрите на **левый цветовой блок** — это ваш целевой цвет
2. Используйте **три ползунка** (Red, Green, Blue) чтобы создать похожий цвет в правом блоке
3. Когда цвет покажется максимально близким, нажмите **"Hit Me!"**
4. Узнайте свой балл за раунд (чем точнее совпадение, тем выше балл)
5. Нажмите **"Continue"** чтобы начать новый раунд
6. Играйте дальше и набирайте очки!

| Точность совпадения | Баллы | Оценка |
|--------------------|-------|--------|
| 100% (идеально) | 100 | Excellent! 🎉 |
| 95% - 99% | 95-99 | Excellent! |
| 90% - 94% | 90-94 | Excellent! |
| 80% - 89% | 80-89 | Excellent! |
| 70% - 79% | 70-79 | Good try! 👍 |
| 60% - 69% | 60-69 | Good try! |
| < 60% | < 60 | Good try! |
