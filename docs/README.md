# Task 3: Body Calculator (BMI + BMR + Volume Calculator)

## 📱 Project Name

**Body Calculator** — приложение для расчёта индекса массы тела (BMI), базального метаболизма (BMR) по формуле Харриса-Бенедикта и объёма геометрических фигур (цилиндр и конус).

## 📝 Description

Приложение объединяет два калькулятора в одном интерфейсе:

### Часть 1: BMI & BMR Calculator
- **Индекс массы тела (BMI)** — оценка соответствия веса росту
- **Базальный метаболизм (BMR)** — количество калорий для поддержания веса в покое (формула Харриса-Бенедикта)
- **Дневная норма калорий** — BMR с учётом физической активности

### Часть 2: Volume Calculator (Вариант 7)
- **Цилиндр** — объём по формуле V = π × R² × H
- **Конус** — объём по формуле V = (1/3) × π × R² × H

### 🎯 Цель работы (Задание 3 + Вариант 7)

1. Реализовать приложение для расчёта индекса массы тела и необходимого количества калорий для поддержания веса
2. Использовать формулы Харриса-Бенедикта и индекса массы тела
3. **Вариант 7:** Добавить расчёт объёма цилиндра и конуса
4. Адаптировать код с Swift 3 на Swift 5
5. Реализовать локализацию на 3 языка (русский, английский, белорусский)

### ✨ Features

- ✅ Расчёт BMI с категориями (от Severe Thinness до Obese Class III)

- ✅ Расчёт дневной нормы калорий с учётом уровня активности (5 уровней)
- ✅ **Расчёт объёма цилиндра (Вариант 7)**
- ✅ **Расчёт объёма конуса (Вариант 7)**

## 📊 Формулы расчёта

### 1. Индекс массы тела (BMI)

```
BMI = Вес (кг) / (Рост (м))²
```

#### Категории BMI

| Диапазон | Категория |
|----------|-----------|
| < 16.0 | Severe Thinness (Выраженный дефицит массы) |
| 16.0 - 16.9 | Moderate Thinness (Умеренный дефицит массы) |
| 17.0 - 18.4 | Mild Thinness (Лёгкий дефицит массы) |
| 18.5 - 24.9 | Normal (Норма) |
| 25.0 - 29.9 | Overweight (Избыточная масса) |
| 30.0 - 34.9 | Obese Class I (Ожирение I степени) |
| 35.0 - 39.9 | Obese Class II (Ожирение II степени) |
| ≥ 40.0 | Obese Class III (Ожирение III степени) |

### 2. Базальный метаболизм (BMR) — Формула Харриса-Бенедикта

```
Для мужчин:
BMR = 88.362 + (13.397 × Вес) + (4.799 × Рост) - (5.677 × Возраст)

Для женщин:
BMR = 447.593 + (9.247 × Вес) + (3.098 × Рост) - (4.330 × Возраст)
```

### 3. Дневная норма калорий

```
Daily Calories = BMR × Activity Multiplier
```

| Уровень активности | Множитель | Описание |
|--------------------|-----------|----------|
| Sedentary | 1.2 | Минимальная или отсутствие упражнений |
| Light | 1.375 | Лёгкие упражнения 1-3 дня/неделю |
| Moderate | 1.55 | Умеренные упражнения 3-5 дней/неделю |
| Very Active | 1.725 | Интенсивные упражнения 6-7 дней/неделю |
| Extra Active | 1.9 | Очень интенсивные упражнения + физическая работа |
